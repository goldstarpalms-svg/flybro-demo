# FlyBro — Premium Flight Discovery & Comparison Platform (Demo)

An independent, premium demonstration of what [flybro.app](https://flybro.app) could become:
a cleaner interface, a smoother user journey, and a more professional travel-booking
experience — built for Amir (project owner) as a product demonstration.

> **This project does not modify, interfere with, or impersonate the production FlyBro
> service.** The original site remains untouched. No private code, credentials, or
> customer data from FlyBro is used.

---

## 1. What this is

A fully interactive flight-comparison **demonstration** for Nigerian domestic travel:

- One-way and round-trip search with full validation
- A deterministic, clearly labelled **sample fare dataset** (never presented as live prices)
- Real results experience: sorting, filtering, flight details, and a **labelled booking
  demonstration** (no payments, no tickets, no fake confirmations)
- Premium, responsive, accessible UI on a documented design system

## 2. Main improvements over the reference

| Area | Reference (flybro.app) | This demo |
| --- | --- | --- |
| Search | Single visible date, minimal controls | Trip type, searchable airport selectors, swap, return date, passengers (adults/children), cabin, inline validation |
| Results | (Not publicly accessible) | Dedicated results view: summary bar, sort (price/time/duration), live filters (airline, price, time, stops, duration), best-value badges |
| Feedback | — | Loading states, empty states with next steps, error states, sample-data disclosure everywhere |
| Journey | Search → handoff | Search → compare → details → booking-handoff simulation, with round-trip leg picker |
| Structure | Single page | Clear IA: hero+search, trending destinations (prefill search), how-it-works, airline directory, why FlyBro, FAQ, footer |
| Accessibility | — | Semantic HTML, labelled controls, keyboard-accessible popovers, focus indicators, reduced-motion support |
| Trust | — | Explicit "sample fare" labels, no invented statistics/testimonials/partnerships, honest FAQ |

## 3. Completed features

- Responsive navigation (desktop + mobile menu) with working in-page navigation
- Hero with search panel as focal point
- Flight search: one-way/round-trip, origin/destination selectors with search + swap,
  date pickers (past dates blocked, return ≥ departure), passenger stepper (1–9 validated),
  cabin class, clear inline errors
- Trending domestic destinations (Lagos → Abuja / Kano / Port Harcourt / Enugu) with
  imagery, indicative sample fares, and one-click route prefill; extra route chips
- How it works (3 steps), airline directory (15 Nigerian carriers, initials avatars),
  why-FlyBro benefits, FAQ accordion (honest answers), full footer
- Results page: search summary with modify-search, result count, lowest sample fare,
  sorting (lowest price / earliest departure / shortest duration), filters (airline,
  max price, departure time, stops, max duration) with reset, mobile filter toggle
- Flight cards: airline, sample flight number, times, airports, duration, stops,
  fare name, baggage, refundability, price, best-value/cheapest/earliest badges
- Flight details modal with sample-itinerary disclosure
- Booking demonstration modal: itinerary summary, totals labelled as sample values,
  explanation of the real airline handoff, **no payment fields, no confirmations**
- Round-trip flow: outbound selection → return selection → combined booking demo
- State handling: initial, validation errors, loading (skeletons), empty results,
  filtered-empty results, error, detail selection, booking selection, mobile menu

## 4. Features that use sample data (explicitly)

- **All fares, schedules, and flight numbers** — generated by a deterministic dataset in
  `src/lib/sampleFlights.ts`, labelled "Sample" throughout the UI
- Indicative "Sample from" prices on destination cards
- Airline logo files (real logos are proprietary assets; clean initials avatars are used)
- The booking handoff itself is simulated (a clearly labelled demonstration step)

## 5. Known limitations

- No live flight data or pricing (by design — no authorised provider credentials)
- Nigerian domestic routes only (matches FlyBro's current product scope)
- Airport set is a curated demo subset (12 airports)
- Inter typeface falls back to the system sans-serif stack when offline
- This demo does not implement accounts, payments, or ticketing — the real product
  doesn't either

## 7. Run & maintain

```bash
npm install
npm run dev        # development server
npm run build      # production build → dist/
npm run preview    # serve the production build locally
npm test           # run the automated tests
```

To deploy: publish this folder to a Git provider and connect it to Vercel/Netlify
(build command `npm run build`, output `dist/`), or any static host. No environment
variables or secrets are required.

## 8. Recommendations for live flight-provider integration

1. Implement `FlightProvider` (see `src/lib/flightProvider.ts`) against a legitimate
   source (e.g. an airline NDC/affiliate API, Amadeus/Sabre, or a local aggregator).
2. Keep the UI untouched — map provider results into the shared flight view-model
   (rename `SampleFlight` → `Flight` when live data lands).
3. **Never ship provider secrets in client-side code** — add a small server/proxy
   layer for API calls and fare caching.
4. Replace the sample labels via a single `isSampleData` flag so the disclosure UI
   switches off automatically when live data is on.
5. Add fare-cache timestamps ("prices seen 12 min ago") — honest freshness beats
   implied live accuracy.
